# John's Service website concept

Premium bid-package website concept for John's Service in Abilene, Kansas.

## Run locally

```powershell
npm install
npm run dev
```

Or double-click `start-website.bat` on Windows.

The launcher uses `http://127.0.0.1:5187/` so it does not collide with the other local Node app using port 5173.

The contact form is currently a front-end prototype and should be connected to the owner's preferred inbox, CRM, or form provider before launch.
